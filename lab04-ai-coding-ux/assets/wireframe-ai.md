# AI-Assisted Text Wireframes (ASCII Layout)

บันทึกการใช้ Prompt สั่งงาน AI เพื่อร่าง Wireframe 3 หน้าจอสำหรับระบบ Inventory
กลุ่มผู้ใช้เป้าหมาย: ป้าพร (วัย 50 ปี, ผู้ดูแลสต็อก/บัญชีอู่, ทักษะเทคโนโลยี 2/5, สายตายาว ต้องการปุ่มใหญ่ สีคอนทราสต์สูง)

---

## 1. Prompt ที่ใช้สั่งงาน AI

```text
ช่วยออกแบบ text wireframe (ASCII layout) สำหรับ 3 หน้าจอของระบบ Inventory Management:
1. หน้า Login (เข้าสู่ระบบ)
2. หน้า Dashboard (สรุปยอดสินค้า + แจ้งเตือนสินค้าใกล้หมด)
3. หน้า Add Product (เพิ่มสินค้าใหม่ เลือกระหว่างสินค้าจับต้องได้ vs ไฟล์ดิจิทัล)

กลุ่มผู้ใช้: พนักงานอู่วัย 50 ปี ทักษะเทคโนโลยี 2/5 ใช้จอ PC ความละเอียด 1366x768 มีปัญหาสายตายาว

ข้อกำหนด Usability & Accessibility:
- ทุกช่องกรอกต้องมี Visible Label อยู่ถาวรด้านบน (ไม่ใช่ placeholder)
- ฟิลด์ที่จำเป็นมีเครื่องหมาย * เด่นชัด
- ปุ่มกดขนาดใหญ่ มีระยะห่างป้องกันการกดผิด ไม่ใช้ปุ่มไอคอนลอยๆ
- มีข้อความ Error ชัดเจนพร้อมวิธีแก้ไข และมี Success Banner ขนาดใหญ่
- สีและคอนทราสต์เป็นไปตามมาตรฐาน WCAG AA
