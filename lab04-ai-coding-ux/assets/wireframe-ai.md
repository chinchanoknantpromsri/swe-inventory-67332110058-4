```markdown
# AI-Assisted Text Wireframes (ASCII Layout)

การออกแบบ Text Wireframe ด้วย AI สำหรับระบบจัดการคลังสินค้า (Inventory Management System)
ผู้ใช้งานเป้าหมาย: ป้าพร (พนักงานคลังสินค้า/บัญชีอู่, อายุ 50 ปี, ทักษะเทคโนโลยี 2/5, สายตายาว ต้องการปุ่มใหญ่ สีคอนทราสต์ชัดเจน)

ประกอบด้วย 3 หน้าจอหลัก:
1. หน้าเข้าสู่ระบบ (Login Page)
2. หน้าแดชบอร์ดสรุปยอดและแจ้งเตือนสต็อกต่ำ (Dashboard Page)
3. หน้าเพิ่มสินค้าใหม่ (Add Product Page - รองรับสินค้าจับต้องได้และสินค้าดิจิทัล)

---

## Screen 1: หน้าเข้าสู่ระบบ (Login Page)

### Prompt ที่ใช้สั่ง AI:

```text
ช่วยออกแบบ text wireframe (ASCII layout) สำหรับ "หน้า Login" ของระบบ Inventory Management
กลุ่มผู้ใช้: พนักงานคลังสินค้า ทักษะเทคโนโลยีระดับ 2/5 ใช้งานผ่าน PC เป็นหลัก
ข้อกำหนด Usability:
- กล่องเข้าสู่ระบบอยู่กึ่งกลางหน้าจอ สะอาดตา ชัดเจน
- ฟิลด์: ชื่อผู้ใช้ (Username)*, รหัสผ่าน (Password)*
- ตัวเลือกจดจำการเข้าสู่ระบบ (Remember Me) และลิงก์ลืมรหัสผ่าน
- ปุ่ม "เข้าสู่ระบบ" (Primary Button) เด่นชัด
- แสดงสถานะ Validation Error เมื่อกรอกข้อมูลไม่ถูกต้อง
ข้อกำหนด Accessibility:
- ทุกฟิลด์มี Visible Label ถาวรเหนือช่องกรอก (ไม่ใช่ Placeholder อย่างเดียว)
- Required field มีเครื่องหมาย * ชัดเจน
- Error message มีไอคอนและข้อความอธิบายวิธีแก้ชัดเจน
- เรียงลำดับ Tabindex จากบนลงล่างอย่างถูกต้อง
ขอผลเป็น ASCII layout พร้อมคำอธิบายว่าแต่ละองค์ประกอบช่วย usability อย่างไร

```

### ASCII Layout ผลลัพธ์:

```text
+-----------------------------------------------------------------------------+
|  SWE INVENTORY MANAGEMENT SYSTEM                              [Help] [TH/EN]|
+-----------------------------------------------------------------------------+
|                                                                             |
|                                                                             |
|                     +----------------------------------+                    |
|                     |         เข้าสู่ระบบ (LOGIN)       |                    |
|                     +----------------------------------+                    |
|                     |                                  |                    |
|                     |  ชื่อผู้ใช้งาน (Username) *       |                    |
|                     |  [ pornsawan_p                 ] |                    |
|                     |                                  |                    |
|                     |  รหัสผ่าน (Password) *            |                    |
|                     |  [ ••••••••••••••••        ] [ตา] |                    |
|                     |                                  |                    |
|                     |  [X] จดจำการเข้าสู่ระบบ           |                    |
|                     |                                  |                    |
|                     |  +----------------------------+  |                    |
|                     |  |     เข้าสู่ระบบ (LOGIN)     |  |                    |
|                     |  +----------------------------+  |                    |
|                     |                                  |                    |
|                     |  ลืมรหัสผ่าน? ติดต่อผู้ดูแลระบบ   |                    |
|                     +----------------------------------+                    |
|                                                                             |
|                                                                             |
+-----------------------------------------------------------------------------+

```

**คำอธิบายด้าน Usability & Accessibility:**

* **Visible Labels:** แสดงป้ายกำกับชื่อผู้ใช้และรหัสผ่านค้างไว้ตลอดเวลา ไม่หายไปเมื่อเริ่มพิมพ์
* **Show/Hide Password:** มีปุ่มรูปดวงตาช่วยให้ผู้ใช้ตรวจสอบรหัสผ่านได้ ป้องกันการพิมพ์ผิดจากปัญหาสายตายาว
* **ปุ่มกดขนาดใหญ่:** ปุ่มล็อกอินมีขนาดใหญ่และอยู่กึ่งกลาง เพิ่มพื้นที่เป้าหมายการคลิก (Click Target) ตามมาตรฐาน WCAG

## Screen 2: หน้าแดชบอร์ดสรุปยอดและแจ้งเตือนสต็อกต่ำ (Dashboard Page)

### Prompt ที่ใช้สั่ง AI:

```text
ช่วยออกแบบ text wireframe (ASCII layout) สำหรับ "หน้า Dashboard" ของระบบ Inventory Management
กลุ่มผู้ใช้: ป้าพร วัย 50 ปี ทักษะไอที 2/5 จอ PC 1366x768
ข้อกำหนด Usability & Accessibility:
- แสดง Summary Cards 3 ใบ: มูลค่ารวม, สินค้าจับต้องได้, สินค้าดิจิทัล
- แถบแจ้งเตือนสต็อกต่ำ (Low Stock Banner) เด่นชัด มีทั้งสีและไอคอน ไม่พึ่งสีอย่างเดียว
- ตารางแสดงรายการที่ใกล้หมด พร้อมปุ่มกดดำเนินการเติมสินค้าทันที
- ปุ่มสร้างรายการสินค้าใหม่โดดเด่นที่แถบด้านบน

```

### ASCII Layout ผลลัพธ์:

```text
+-----------------------------------------------------------------------------+
| [โลโก้] คลังอะไหล่และเอกสาร | หน้าแรก | รายการสินค้า | รายงาน |  [+ เพิ่มสินค้าใหม่] |
+-----------------------------------------------------------------------------+
|                                                                             |
|  [!] แจ้งเตือนด่วน: มีสินค้าใกล้หมด 2 รายการ กรุณาตรวจสอบและสั่งซื้อเพิ่ม   |
|                                                                             |
|  +---------------------+  +---------------------+  +---------------------+  |
|  | มูลค่ารวมสินค้าคงคลัง|  | สินค้ามีของจริง (ชิ้น) |  | คู่มือ/ไฟล์ดิจิทัล  |  |
|  |   ฿ 145,200.00      |  |       128 ชิ้น      |  |      12 รายการ      |  |
|  +---------------------+  +---------------------+  +---------------------+  |
|                                                                             |
|  ตารางแจ้งเตือนสินค้าใกล้หมด (Low Stock Alert):                             |
|  +-----------------------+-------------+----------+-----------+----------+  |
|  | ชื่อสินค้า / อะไหล่    | ชนิดสินค้า  | คงเหลือ  | สถานะ     | จัดการ   |  |
|  +-----------------------+-------------+----------+-----------+----------+  |
|  | น้ำมันเครื่อง 10W-40   | มีของจริง   | 2 แกลลอน | [สต็อกต่ำ]| [เติมของ]|  |
|  | ผ้าเบรกหน้า City/Jazz  | มีของจริง   | 1 ชุด    | [สต็อกต่ำ]| [เติมของ]|  |
|  | คู่มือซ่อมวงจรไฟ (PDF) | ไฟล์ดิจิทัล | ส่งลิงก์ | [ปกติ]    | [ดูไฟล์] |  |
|  +-----------------------+-------------+----------+-----------+----------+  |
|                                                                             |
+-----------------------------------------------------------------------------+

```

**คำอธิบายด้าน Usability & Accessibility:**

* **Multimodal Warning:** การแจ้งเตือนสต็อกต่ำใช้ทั้งไอคอนเครื่องหมายตกใจ `[!]` และข้อความกำกับ ไม่พึ่งพาการสื่อสารด้วยสีเพียงอย่างเดียว
* **Summary Cards:** แยกสถิติสินค้ามีของจริงและไฟล์ดิจิทัลให้เห็นชัดเจน ป้องกันความสับสนในการตรวจนับสต็อก

## Screen 3: หน้าเพิ่มสินค้าใหม่ (Add Product Page - รองรับสินค้าจับต้องได้และดิจิทัล)

### Prompt ที่ใช้สั่ง AI:

```text
ช่วยออกแบบ text wireframe (ASCII layout) สำหรับ "หน้าเพิ่มสินค้าใหม่" รองรับทั้ง Physical Item และ Digital Item
กลุ่มผู้ใช้: ป้าพร วัย 50 ปี ทักษะไอที 2/5
ข้อกำหนด Usability & Accessibility:
- ตัวเลือกชนิดสินค้า (Radio Button) ชัดเจนตั้งแต่ข้อแรก
- ถ้าเลือกสินค้าดิจิทัล ฟิลด์จำนวนสต็อกจะถูก disable อัตโนมัติ
- ฟิลด์ที่จำเป็นมีเครื่องหมาย * เด่นชัด
- ข้อความแจ้งเตือนข้อผิดพลาด (Validation Error) ชัดเจนพร้อมบอกวิธีแก้
- ปุ่มบันทึกขนาดใหญ่ และเว้นระยะห่างจากปุ่มยกเลิก ป้องกันการคลิกพลาด

```

### ASCII Layout ผลลัพธ์:

```text
+-----------------------------------------------------------------------------+
| < ย้อนกลับไปหน้าแรก                    เพิ่มรายการสินค้าใหม่                 |
+-----------------------------------------------------------------------------+
|                                                                             |
|  [✓] บันทึกสำเร็จ: อะไหล่ 'น้ำมันเกียร์ ATF' ถูกเพิ่มลงในระบบเรียบร้อยแล้ว   |
|                                                                             |
|  1. เลือกชนิดของสินค้า *                                                    |
|     (*) สินค้าจับต้องได้ / อะไหล่จริง        ( ) สินค้าดิจิทัล / ไฟล์คู่มือ  |
|         (มีสต็อกจริง ต้องตรวจนับ)                (ไม่มีสต็อก ส่งลิงก์โหลด)   |
|                                                                             |
|  2. ชื่อสินค้าหรืออะไหล่ *                                                  |
|     [ น้ำมันเกียร์อัตโนมัติ ATF 1 ลิตร                                  ]   |
|                                                                             |
|  3. จำนวนสต็อกเริ่มต้น (ชิ้น) * (ปิดอัตโนมัติหากเลือกสินค้าดิจิทัล)         |
|     [ 15                                                            ]       |
|     ! ข้อผิดพลาด: กรุณากรอกเป็นตัวเลขจำนวนเต็มบวก                           |
|                                                                             |
|  4. ราคาต่อหน่วย (บาท) *                                                    |
|     [ 350.00                                                        ]       |
|                                                                             |
|  -------------------------------------------------------------------------  |
|                                 [ ยกเลิก ]      [   ปุ่มใหญ่: บันทึกข้อมูล  ] |
|                                                                             |
+-----------------------------------------------------------------------------+

```

**คำอธิบายด้าน Usability & Accessibility:**

* **Explicit Type Selection:** กำหนดคำอธิบายความแตกต่างของชนิดสินค้าใต้ Radio Button อย่างละเอียด
* **Error Guidance:** แจ้งเตือนข้อผิดพลาดใต้ช่องกรอกโดยตรง พร้อมบอกวิธีแก้ไข ไม่ใช้ข้อความกว้างๆ เช่น "ข้อมูลไม่ถูกต้อง"
* **Action Separation:** วางปุ่ม "บันทึกข้อมูล" แยกห่างจากปุ่ม "ยกเลิก" เพื่อลดโอกาสที่ผู้สูงอายุจะคลิกพลาด

```
